# 🎯 دانلودر یوتیوب (با GitHub Actions)

**FA** | [English Version](README.md)

دانلود خودکار ویدیوهای یوتیوب با استفاده از GitHub Actions – بدون نیاز به هیچ ابزار محلی، **رایگان و بدون نیاز به اینترنت بین‌المللی**.  
ویدیوها مستقیماً در ریپازیتوری شما ذخیره می‌شوند، با امکان زیرنویس، انتخاب کیفیت و محافظت با رمز عبور.

## ✨ ویژگی‌ها

- 📥 دانلود یک یا چند ویدیو همزمان
- 🎬 انتخاب کیفیت: بهترین، 4K، 2K، 1080p، 720p، 480p یا فقط صدا
- 📝 دانلود زیرنویس فارسی و/یا انگلیسی (دستی + خودکار)
- 🔒 محافظت فایل‌ها با رمز عبور (اختیاری)
- 📦 تقسیم خودکار ویدیوهای بزرگ به بخش‌های ۴۵ مگابایتی برای مدیریت راحت‌تر
- 🖼️ تصویر بندانگشتی (thumbnail) در پوشه هر ویدیو
- 📄 فایل `README.md` کامل برای هر ویدیو با لینک دانلود، اطلاعات فایل و راهنمای استخراج
- 🌐 استفاده از پروکسی Cloudflare WARP در محیط اجرا برای اتصال بهتر

## 🚀 روش استفاده

### ۱. یک کپی برای خودتان بسازید

این ریپازیتوری را Fork کنید، یا یک ریپازیتوری جدید بسازید و فایل workflow را در مسیر `.github/workflows/` کپی کنید.

> نام فایل workflow: `01 - 🎯 دانلود یوتیوب.yml`

### ۲. فعال‌سازی GitHub Actions

مطمئن شوید Actions در تنظیمات ریپازیتوری شما فعال باشد (معمولاً به‌طور پیش‌فرض فعال است).

### ۳. اجرای workflow

۱. به تب **Actions** در ریپازیتوری خود بروید.  
۲. workflow **01 - 🎯 دانلود یوتیوب** را انتخاب کنید.  
۳. روی **Run workflow** کلیک کنید.  
۴. پارامترها را پر کنید:

| پارامتر              | توضیحات |
|----------------------|----------|
| `video_urls`         | **الزامی.** لینک(های) یوتیوب. چند لینک را با فاصله جدا کنید. |
| `download_subtitles` | برای دانلود زیرنویس فارسی و انگلیسی تیک بزنید. |
| `quality`            | کیفیت و نوع: `best`، `2160`، `1440`، `1080`، `720`، `480` یا `audio`. |
| `password`           | رمز عبور دلخواه برای محافظت از فایل zip (اختیاری). |

۵. روی **Run workflow** کلیک کنید.

### ۴. یافتن فایل‌های دانلود شده

بعد از اتمام workflow:

- به پوشه `videos/` در ریپازیتوری خود بروید.
- هر ویدیو در زیرپوشه مخصوص خودش ذخیره می‌شود.
- داخل آن فایل ویدیو (یا بخش‌های تقسیم‌شده)، یک `thumbnail.jpg` و یک `README.md` با لینک‌های دانلود و راهنمای استخراج پیدا می‌کنید.

## 📖 نمونه README ویدیو

هر پوشه ویدیو یک فایل `README.md` شبیه این دارد:

```markdown
# عنوان ویدیوی من
<div align="center">
  <picture>
    <img src="thumbnail.jpg" width="250" />
  </picture>
</div>

---
## اطلاعات ویدیو
| ویژگی | مقدار |
|-------|-------|
| **نام ویدیو** | `My-Video-Title` |
| **لینک اصلی** | [ویدیوی یوتیوب](https://youtube.com/...) |
| **حجم کل** | **۳ بخش** - **۱۳۴.۵۰ مگابایت** |
| **کیفیت** | **1080** |
| **وضعیت** | **کامل (۱۰۰٪)** |
| **محافظت با رمز** | **خیر** |

---
## لینک‌های دانلود
> ⬇️ **همه بخش‌ها** را دانلود کنید، سپس فایل `My-Video-Title.zip` را باز کنید — بقیه بخش‌ها خودکار شناسایی می‌شوند.

| # | فایل | لینک |
|---|------|------|
| ۱ | `My-Video-Title.zip` | [دانلود](raw-link) |
| ۲ | `My-Video-Title.z01` | [دانلود](raw-link) |
| ۳ | `My-Video-Title.z02` | [دانلود](raw-link) |

---
## روش استخراج
همه بخش‌ها را در **یک پوشه** دانلود کنید، سپس:
...
```

## 📦 کار با آرشیوهای تقسیم‌شده

اگر حجم فایل بیشتر از ۴۵ مگابایت باشد، به‌طور خودکار به بخش‌هایی تقسیم می‌شود:
- `.zip` – آرشیو اصلی
- `.z01`، `.z02` و … – بخش‌های بعدی

**برای استخراج:**
- **ویندوز**: روی فایل `.zip` راست‌کلیک کنید → *Extract Here* (با 7-Zip یا WinRAR)
- **مک**: روی `.zip` دابل‌کلیک کنید (Keka یا The Unarchiver)
- **لینوکس**: `unzip My-Video-Title.zip`
- **اندروید**: از ZArchiver استفاده کنید

اگر رمز عبور تنظیم شده باشد، هنگام استخراج از شما خواسته می‌شود.

## 🔤 زیرنویس‌ها

وقتی گزینه زیرنویس فعال باشد، یک فایل `subtitle.zip` به پوشه ویدیو اضافه می‌شود. این فایل حاوی زیرنویس‌های `.vtt` فارسی (`fa`) و انگلیسی (`en`)، هم دستی و هم خودکار (در صورت موجود بودن) است.

## 🛠️ جزئیات فنی

- workflow روی **Ubuntu** با محدودیت زمانی **۱۸۰ دقیقه** اجرا می‌شود.
- از [`yt-dlp`](https://github.com/yt-dlp/yt-dlp) برای دانلود ویدیوها استفاده می‌کند.
- یک پروکسی **Cloudflare WARP** در محیط اجرا راه‌اندازی می‌شود تا از محدودیت‌های منطقه‌ای یا rate-limiting جلوگیری کند.
- چندین روش دانلود (با player clientهای مختلف) برای اطمینان از موفقیت امتحان می‌شود.
- فایل‌ها مستقیماً با استفاده از ربات GitHub Actions در ریپازیتوری commit می‌شوند.
- لیست اصلی در `videos/README.md` به‌طور خودکار با لینک به پوشه هر ویدیو به‌روزرسانی می‌شود.

## ❓ عیب‌یابی

- **workflow بدون فایل ویدیویی با خطا مواجه می‌شود**: بررسی کنید که لینک یوتیوب معتبر باشد و ویدیو خصوصی یا دارای محدودیت سنی نباشد.
- **Push ناموفق است**: workflow تا ۱۰ بار تلاش مجدد می‌کند. فایل‌های بزرگ ممکن است کمی طول بکشند. مطمئن شوید ریپازیتوری شما محدودیت حجمی خاصی نداشته باشد (گیت‌هاب محدودیت نرم حدود ۱ گیگابایت برای هر ریپازیتوری دارد، اما فایل‌های باینری بزرگ توصیه نمی‌شوند).
- **پروکسی WARP راه‌اندازی نشد**: workflow در هر حال ادامه می‌یابد؛ فقط ممکن است کندتر باشد یا در برخی مناطق مسدود شود.
